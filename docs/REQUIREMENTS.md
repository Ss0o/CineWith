# 요구사항

## 목적

이 문서는 V1 제품 범위와 성공 조건에 대한 기준 문서다.

## 범위

V1은 영화 리뷰 및 추천 커뮤니티를 제공한다. Google OAuth2 인증, 회원 정보, 영화 탐색, 평점을 포함한 리뷰, 리뷰에 대한 댓글을 지원한다.

## 기능 요구사항

### 인증

| ID | 요구사항 | 성공 조건 |
| --- | --- | --- |
| AUTH-001 | 사용자는 Google OAuth2를 이용해 외부 IdP 인증을 완료할 수 있다. | Google 인증을 성공적으로 완료하면 외부 IdP를 통한 신원 확인이 완료된 상태로 인식된다. 인증에 실패하거나 취소하면 인증 완료 상태가 되지 않는다. OAuth2 인증 완료만으로 서비스 회원가입이 완료되지는 않는다. |
| AUTH-002 | 서비스는 OAuth2 인증 완료 상태와 회원가입이 완료된 로그인 상태를 구분한다. | OAuth2 인증 후 `Member`가 없으면 가입용 닉네임을 설정할 수 있지만 리뷰·댓글 작성 등 회원 전용 기능은 사용할 수 없다. DB에 `Member`가 존재하는 사용자는 회원 전용 기능을 사용할 수 있다. |
| AUTH-003 | 서비스는 서버 세션으로 인증 및 로그인 상태를 관리한다. | 유효한 서버 세션과 연결된 요청에서 사용자의 OAuth2 인증 여부와 회원가입 완료 여부를 구분할 수 있다. 세션이 없거나 만료 또는 무효화된 경우에는 인증된 사용자로 인식되지 않는다. 구체적인 세션 저장 구조는 이후 설계한다. |
| AUTH-004 | 인증된 사용자는 로그아웃할 수 있다. | 로그아웃 성공 후 해당 서버 세션으로 보내는 요청은 더 이상 인증되지 않는다. |

### 회원

| ID | 요구사항 | 성공 조건 |
| --- | --- | --- |
| MEMBER-001 | 최초 OAuth2 인증 사용자는 닉네임 설정을 완료한 후 서비스 회원으로 등록된다. | Google OAuth2 인증 성공 후 `provider + providerId`로 회원을 조회한다. 회원이 없으면 가입 진행 상태로 이동하며, 사용자가 유효한 닉네임을 설정한 후에만 `Member`가 생성되고 서비스 회원가입이 완료된다. |
| MEMBER-002 | 기존 OAuth2 사용자는 `provider + providerId` 조합으로 식별하며 중복 회원을 생성하지 않는다. | 같은 `provider + providerId`로 반복 로그인하면 기존 회원을 사용하며, 해당 조합에 대응하는 회원은 정확히 하나만 존재한다. |
| MEMBER-003 | 로그인한 회원은 자신의 회원 정보를 조회할 수 있다. | 로그인한 회원은 자신의 회원 정보를 조회할 수 있다. 로그인하지 않은 사용자는 이 기능을 통해 회원 정보를 조회할 수 없다. |
| MEMBER-004 | 회원은 커뮤니티에서 사용할 닉네임을 보유한다. | 등록된 회원은 자신의 리뷰와 댓글에 표시할 수 있는 닉네임을 가진다. |
| MEMBER-005 | 회원의 닉네임은 중복될 수 없다. | 이미 다른 회원이 사용 중인 닉네임으로는 회원가입을 완료할 수 없으며, 가입이 완료된 각 회원의 닉네임은 서로 다르다. |

### 영화

| ID | 요구사항 | 성공 조건 |
| --- | --- | --- |
| MOVIE-001 | 사용자는 TMDB API를 이용해 영화를 검색할 수 있다. | 지원하는 검색 조건으로 요청하면 TMDB에서 가져온 일치하는 영화 정보를 반환한다. |
| MOVIE-002 | 사용자는 TMDB에서 제공하는 영화의 기본 상세 정보를 조회할 수 있다. | 조회 가능한 영화의 기본 정보를 TMDB에서 가져와 반환한다. |
| MOVIE-003 | 사용자는 특정 영화를 기준으로 TMDB 추천 영화 목록을 조회할 수 있다. | 조회 가능한 영화를 지정하면 TMDB에서 가져온 추천 영화 목록을 반환한다. |
| MOVIE-004 | 서비스는 TMDB 전체 영화를 미리 저장하지 않고 리뷰가 작성된 영화의 최소 정보만 저장한다. | 검색·상세·추천 조회만으로는 TMDB 영화를 서비스 DB에 저장하지 않는다. 리뷰 작성 시 대상 영화가 없으면 해당 영화의 서비스에 필요한 최소 정보만 저장하며, 실제 리뷰가 작성된 영화만 DB에 존재한다. |

TMDB 저장 정보의 갱신 정책과 세부 연동 방식은 이후 도메인 및 외부 연동 설계에서 결정한다.

### 리뷰

| ID | 요구사항 | 성공 조건 |
| --- | --- | --- |
| REVIEW-001 | 로그인한 회원만 특정 영화에 대한 리뷰를 작성할 수 있다. | 로그인한 회원은 선택한 영화와 연결된 리뷰를 작성할 수 있으며 작성자로 기록된다. 로그인하지 않은 사용자는 리뷰를 작성할 수 없다. |
| REVIEW-002 | 리뷰는 사용자 기준 `0.5`부터 `5.0`까지 `0.5` 단위의 평점을 포함한다. | 허용 범위와 단위에 맞는 평점이 있어야 리뷰를 작성하거나 수정할 수 있다. 사용자 평점은 내부 도메인에서 `1`부터 `10`까지의 정수로 표현된다. |
| REVIEW-003 | 누구나 리뷰 목록을 조회할 수 있다. | 로그인하지 않아도 리뷰를 조회할 수 있으며, 기본적으로 한 페이지에 20개씩 최신 작성순으로 반환한다. |
| REVIEW-004 | 누구나 리뷰 상세 내용을 조회할 수 있다. | 로그인하지 않아도 존재하는 리뷰의 상세 내용을 조회할 수 있다. |
| REVIEW-005 | 리뷰 작성자만 자신의 리뷰를 수정할 수 있다. | 작성자는 자신의 리뷰를 수정할 수 있다. 로그인하지 않은 사용자를 포함해 작성자가 아닌 사용자는 수정할 수 없다. |
| REVIEW-006 | 리뷰 작성자만 자신의 리뷰를 삭제할 수 있다. | 작성자는 자신의 리뷰를 삭제할 수 있다. 로그인하지 않은 사용자를 포함해 작성자가 아닌 사용자는 삭제할 수 없다. |
| REVIEW-007 | 한 회원은 같은 영화에 리뷰를 하나만 작성할 수 있다. | 동일한 `Member + Movie` 조합으로 두 개 이상의 리뷰를 생성할 수 없다. |
| REVIEW-008 | 영화 평균 평점은 별도 저장하지 않고 리뷰 데이터를 기준으로 계산한다. | 평균 평점이 필요할 때 해당 영화의 리뷰 평점을 기준으로 계산하며, V1의 `Movie`에는 평균 평점 필드를 저장하지 않는다. |

### 댓글

| ID | 요구사항 | 성공 조건 |
| --- | --- | --- |
| COMMENT-001 | 댓글은 특정 리뷰에 속한다. | 생성된 댓글은 정확히 하나의 리뷰와 연결되며 해당 리뷰의 댓글로 조회된다. |
| COMMENT-002 | 누구나 특정 리뷰의 댓글 목록을 조회할 수 있다. | 로그인하지 않아도 존재하는 리뷰의 댓글 목록을 조회할 수 있다. |
| COMMENT-003 | 로그인한 회원만 리뷰에 댓글을 작성할 수 있다. | 로그인한 회원은 선택한 리뷰와 연결된 댓글을 작성할 수 있으며 작성자로 기록된다. 로그인하지 않은 사용자는 댓글을 작성할 수 없다. |
| COMMENT-004 | 댓글 작성자만 자신의 댓글을 수정할 수 있다. | 댓글 작성자는 자신의 댓글을 수정할 수 있다. 리뷰 작성자를 포함해 댓글 작성자가 아닌 사용자는 수정할 수 없다. |
| COMMENT-005 | 댓글 작성자만 자신의 댓글을 삭제할 수 있다. | 댓글 작성자는 자신의 댓글을 삭제할 수 있다. 리뷰 작성자를 포함해 댓글 작성자가 아닌 사용자는 삭제할 수 없다. |
| COMMENT-006 | V1에서 댓글 삭제는 Hard Delete로 처리한다. | 삭제에 성공한 댓글은 서비스에서 물리적으로 제거되며 삭제 상태로 보존되지 않는다. |

## V1 범위 제외 및 향후 확장 기능

다음 기능은 V1 범위에서 제외하며 향후 확장 가능 기능으로만 기록한다.

- 좋아요
- 이미지 직접 첨부
- 대댓글
- 팔로우
- 관리자 및 모더레이션
- 회원 탈퇴
- 개인화 추천 알고리즘

기술적인 클래스 설계, DB 테이블 설계, API URL, 외부 영화 API 구현 방법도 이번 요구사항 결정 범위에 포함하지 않는다.

## 미결정 사항

- 가입 중 OAuth 사용자 정보는 HTTP Session의 인증 Principal에 유지하며, 구체적인 Session 수명은 미결정
- 가입 진행 중 세션 만료, 닉네임 중복 요청, 가입 재시도 시 처리 방식
- 닉네임 길이, 허용 문자, 변경 가능 여부
- 저장하고 반환할 회원 정보와 email 갱신 정책
- 세션 수명, 갱신, 동시 로그인, 쿠키, 로그아웃 무효화 정책
- TMDB가 제공하는 검색 조건 및 영화 상세 필드
- TMDB 저장 정보 갱신 정책
- 리뷰 내용 필드와 content 검증 규칙, 선택 가능한 페이지 크기와 최대 페이지 크기
- 댓글 content 검증, 정렬, 페이지네이션 정책
- 존재하지 않거나 삭제되었거나 외부에서 조회할 수 없는 영화, 리뷰, 댓글의 표현 방식
- 리뷰 삭제 방식 및 리뷰 삭제 시 댓글 처리 방식
- 콘텐츠 수정 이력 또는 감사 기록 보존 여부
- 도메인별 Aggregate 경계
- 내부 ID의 외부 노출 여부
- V1 이후 회원 탈퇴 도입 시 데이터 보존 및 콘텐츠 처리 방식
- 지원 클라이언트, 배포 환경, 가용성·관측성·접근성·지역화 등의 비기능 목표
